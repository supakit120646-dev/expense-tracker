#  Expense Tracker Dashboard

A web-based application for tracking daily expenses, visualizing data with interactive dashboards, and filtering records by date/category. This project is part of the internship assessment submission.

🔗 **Live Demo:** [ใส่ลิงก์ App ของคุณที่ได้จาก Streamlit Cloud ตรงนี้]

##  Key Features
- **Add Expenses:** Record transactions with Date, Time, Category, Description, and Amount.
- **Interactive Dashboard:** View total expenses, average spending, and visual charts (Pie & Scatter plots).
- **Search & Filter:** Filter data by date range and search by keywords (e.g., category or description).
- **Mock Data Generator:** Built-in tool to generate sample data for testing purposes.
- **Responsive Table:** Sortable and clean data table sorted by timestamp.

##  Tech Stack
- **Language:** Python 3
- **Library:** Streamlit (Web Framework)
- **Data Handling:** Pandas
- **Visualization:** Plotly Express
